# Enforce the AI-only policy at build time via a custom MSBuild SDK facade

## Context and Problem Statement

The AI-only invariant ([ADR-0001](0001-ai-only-gating.md)) is checked at
evaluation time, but a convention that lives only in runtime code can be
forgotten or quietly bypassed when a new project is added. We want the policy to
be a *structural* property of a consuming project, asserted by the build itself,
not a paragraph in a README.

## Decision Drivers

- The invariant should be enforced where projects are defined (the build), not only where they run.
- Wiring it into a new project should be a single, declarative step.
- The enforcement assets should be regenerable, so the policy and its scaffolding cannot drift apart by hand-editing.

## Considered Options

- Documentation-only convention.
- A Roslyn analyzer that flags non-conforming projects.
- A custom MSBuild SDK facade that imports enforcement `props`/`targets`.

## Decision Outcome

Chosen option: "MSBuild SDK facade". `src/Sdk/AiEvalGate.NET.Sdk` is a thin SDK
whose `Sdk.props`/`Sdk.targets` import `Build/Enforcement/AiEvalGateEvaluation.props`
and `.targets`, which set `AiEvalGateEvaluationRequired=true` and emit a policy
banner target. A project opts in with a single `<Project Sdk="...">` reference.
The entire SDK, the enforcement assets, the AI reviewer personas, and the CI
scaffolding are regenerated by `eng/AiEvalGate.ScaffoldGenerator`, so the policy
and its plumbing are produced from one source of truth.

### Consequences

- Good, because the policy is enforced declaratively at build time and is hard to bypass silently.
- Good, because regeneration keeps the SDK, policy, and CI in lock-step.
- Bad, because it adds MSBuild indirection that a casual reader must learn.
- Neutral, because the facade is intentionally thin — it imports the real `Microsoft.NET.Sdk` and only layers enforcement on top.

## Validation

`eng/AiEvalGate.ScaffoldGenerator` round-trips the SDK, enforcement assets, and
reviewer scaffolding; projects consuming `AiEvalGate.NET.Sdk` receive the
enforcement import and policy banner at build time.
